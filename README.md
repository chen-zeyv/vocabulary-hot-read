# 词汇热读

把当天在学或在复习的英语单词，放进最近 7 天的英语热点新闻里练阅读。

## 怎么用
- 粘贴当天单词，选热点类别，检索最近 7 天的热点。
- 选一条热点，用 DeepSeek 生成一篇英语短文和 5 道练习。
- 练习题在浏览器本地判分。

## 使用前须知
- 需要自备 DeepSeek API 密钥，在页面输入框填写；请求从浏览器直接发往 DeepSeek，本站没有服务器。
- 密钥只留在当前页面会话，刷新即清除。
- 调用 DeepSeek 可能产生费用，由使用者自己的账户承担。
- 词汇、搜索结果、文章和练习不会上传到本站，也不被保存。

## 已知限制
- 目前只支持 DeepSeek 一个服务商。
- 热点按类别检索，默认全球英语来源、最近 7 天。
- 练习为本地判分，不记录成绩。
