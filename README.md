# 词汇热读

把当天在学或在复习的英语单词，放进最近的英语热点里练阅读。纯静态页面，本站没有服务器。

## 怎么用
- 粘贴当天要练的单词，一行一个，个数不限；重复词会自动合并。
- 填 1–5 个热点标签（可从快捷标签里挑，也可以自己输入），选择内容范围，检索最近 7 天的热点。
- 内容范围默认「身边日常」，避免总是国际大事；也可以选「本城市 / 地区」手填城市名，或点「用当前位置」自动填入。
- 选一条热点，用 DeepSeek 生成一篇英语短文和 5 道练习。
- 生成成功后，本次真正用到的目标词会从输入框移除，没轮到的词留到下次；点「恢复上次移除的词」可以放回上一批。
- 生成文章后，正文下方会显示一张来源文章配图，图注含站点名、标题和原文链接；点任意英文单词可以听发音。
- 练习题在浏览器本地判分，不记录成绩。
- 01 屏可切换「小说精读」：三步为准备 / 选章节 / 阅读；章节可粘贴、上传 .txt、填书名与章节名后 Search 再 Fetch，或直接粘贴章节链接取回。取回后 02 屏会显示前 200 字原文预览，请先核对是否为章节正文。

## 可调项
- 英语难度 6 档（A1–C2）、文章长度 7 档（约 100–340 词）、目标词密度 3 档（稀疏 / 正常 / 密集）。
- 目标词数量不再手选，由上面三项算出 3–15 个，并显示本次实际使用的词表。
- 练习题型 8 种可选 2–5 种，固定 5 题，每种至少 1 道。
- 候选中文对照默认关闭；打开后会把最多 5 条候选的标题和摘要发给 DeepSeek 翻译一次，多一次请求和费用。
- 文章中文全文翻译默认关闭，也会增加发送内容和费用。
- 小说长度 5 档（约 300 / 450 / 600 / 800 / 1000 词），密度滑杆每千词 6–32（步长 2），目标词 3–24 且不超过输入词数；小说不做题、不配图。

## 使用前须知
- 搜索和生成共用一个 DeepSeek API Key，只需填一次。
- 需要自备 DeepSeek API 密钥，在页面输入框填写；请求从浏览器直接发往 DeepSeek，本站没有服务器。
- 密钥只留在当前页面会话，刷新即清除；页面脚本和开发者工具可以访问它。
- 调用 DeepSeek 可能产生费用，由使用者自己的账户承担。一次正常流程是 1 次搜索 + 1 次生成 + 1 次 microlink 元数据请求（用于取来源文章配图）；确认修订时再加 1 次生成。
- 来源配图读取的是网页自己声明的 og:image，图片由浏览器直接从来源站点加载，本站不转存图片；取不到时整块不显示，不影响阅读和做题。
- 点「用当前位置」时，坐标只发给浏览器定位服务与 BigDataCloud 换取城市名，页面不保存坐标；拒绝授权或定位失败时可以手填城市。
- 词汇、搜索结果、文章和练习不会上传到本站，也不被保存。
- 小说自动获取章节时，查找与取回各计 1 次 Search 与 1 次 Fetch，生成和修订各 1 次 Chat；小说不请求 microlink。章节正文上限 15,000 字符，只留在当前页面内存。
- 小说提示词会争取至少覆盖 60%、不少于 3 个目标词（词数不足时按实际数量），但实际覆盖仍以页面匹配结果为准；词表最好与章节同主题。

## 已知限制
- 目前只支持 DeepSeek 一个服务商，其他服务商选项为未验证、禁用状态。
- 热点按标签检索，默认最近 7 天的英语来源；实际命中范围受 DeepSeek Search 返回结果限制。
- 来源配图每篇文章最多 1 张，只接受合格的 HTTPS 图片；站点限制外链、图片过小或取不到时不显示。
- 文章基于检索摘要生成，不是新闻原文，页面上会标注。
- 练习为本地判分，不记录成绩。
- 小说按用户提供的章节改写成英文学习版，保留人物、关系与关键情节，不新增原文没有的情节；作品版权与使用范围由使用者自行负责。
- Fetch 失败时请换一条候选；出版社、新闻、阅读类站点通常能取回，扫描件与 PDF 站点常返回 404。
- 命中页面框架/摘要信号时不写入正文，只显示预览并提示换候选或直接粘贴正文。
- 静态外壳缓存版本为 `vocabulary-hot-read-shell-v27`。
