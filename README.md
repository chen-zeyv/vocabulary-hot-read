# 词汇热读

把当天在学或在复习的英语单词，放进最近的英语热点里练阅读。纯静态页面，本站没有服务器。

## 怎么用
- 粘贴当天要练的单词，一行一个，个数不限；重复词会自动合并。
- 填 1–5 个热点标签（可从快捷标签里挑，也可以自己输入），选择内容范围，检索最近 7 天的热点。
- 内容范围默认「身边日常」，避免总是国际大事；也可以选「本城市 / 地区」手填城市名，或点「用当前位置」自动填入。
- 选一条热点，用 DeepSeek 生成一篇英语短文和 5 道练习。
- 生成成功后，本次真正用到的目标词会从输入框移除，没轮到的词留到下次；点「恢复上次移除的词」可以放回上一批。
- 练习题在浏览器本地判分，不记录成绩。

## 可调项
- 英语难度 6 档（A1–C2）、文章长度 7 档（约 100–340 词）、目标词密度 3 档（稀疏 / 正常 / 密集）。
- 目标词数量不再手选，由上面三项算出 3–15 个，并显示本次实际使用的词表。
- 练习题型 8 种可选 2–5 种，固定 5 题，每种至少 1 道。
- 候选中文对照默认关闭；打开后会把最多 5 条候选的标题和摘要发给 DeepSeek 翻译一次，多一次请求和费用。
- 文章中文全文翻译默认关闭，也会增加发送内容和费用。
- 生成成功后可能显示 1–2 张来源文章原图，图片由浏览器直接从来源站点加载，本站不转存。

## 使用前须知
- 搜索和生成共用一个 DeepSeek API Key，只需填一次。
- 需要自备 DeepSeek API 密钥，在页面输入框填写；请求从浏览器直接发往 DeepSeek，本站没有服务器。
- 密钥只留在当前页面会话，刷新即清除；页面脚本和开发者工具可以访问它。
- 调用 DeepSeek 可能产生费用，由使用者自己的账户承担。一次正常流程是 1 次搜索 + 1 次生成 + 1 次取原图，确认修订时再加 1 次生成；同一候选来回切换不会重复取图。
- 点「用当前位置」时，坐标只发给浏览器定位服务与 BigDataCloud 换取城市名，页面不保存坐标；拒绝授权或定位失败时可以手填城市。
- 词汇、搜索结果、文章和练习不会上传到本站，也不被保存。

## 已知限制
- 目前只支持 DeepSeek 一个服务商，其他服务商选项为未验证、禁用状态。
- 热点按标签检索，默认最近 7 天的英语来源；实际命中范围受 DeepSeek Search 返回结果限制。
- 来源文章原图只取原文中的图片，最多 2 张；站点禁止外链或取不到时只显示中性提示，不影响阅读与做题。
- 文章基于检索摘要生成，不是新闻原文，页面上会标注。
- 练习为本地判分，不记录成绩。
